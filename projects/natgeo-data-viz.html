NatGeo Data Viz Redesign

2024 Lead Product Designer

Redesigned National Geographic's data visualization platform to improve accessibility and user engagement with complex scientific data.

Challenge

National Geographic's existing data visualization tools were difficult for general audiences to understand and interact with. The challenge was to make complex scientific data more accessible while maintaining scientific accuracy.

Solution

I led the design of a new interactive data visualization system that uses progressive disclosure and guided storytelling to help users explore scientific datasets. The new design includes:

  • Simplified visual hierarchy with clear entry points
  • Interactive tutorials that guide users through complex datasets
  • Responsive design optimized for mobile exploration
  • Enhanced accessibility features for screen readers

Results

The redesigned platform saw a 40% increase in user engagement and significantly improved accessibility scores. User testing showed that complex scientific concepts were now understandable to 85% of general audiences, compared to 45% with the previous design.
